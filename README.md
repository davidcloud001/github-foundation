## GitHub Workflow

This is the core workflow I am practicing in this repository:

1. **Repository** — The home for a project and its history.
2. **Commit** — A recorded snapshot of changes.
3. **Branch** — A separate line of development used to make changes safely.
4. **Pull Request** — A request to review and merge changes into another branch.
5. **Merge** — Combines approved changes into the target branch.

### Practical Workflow

**Issue → Branch → Commit → Pull Request → Review → Merge**
